# החזר קל

אפליקציה להכנת בקשות זיכוי מקבלות ושליחתן להנהלת החשבונות. האפיון המלא: `Hechzer-Kal-Spec.md`.

## מצב נוכחי (שלבים 1–3 בסעיף 13)

עובד:
- כניסה למוזמנים בלבד (קישור הזמנה חד־פעמי, סיסמה)
- צילום/העלאה של תמונה או PDF, כולל קבלות שנשמרו מהמייל
- הזנת סכום וסוג הוצאה; ״אחר״ מחייב תיאור
- בקשה עם קבלה אחת או יותר, תצוגת המייל המלא ואישור
- חסימת העלאה חוזרת של אותו קובץ, ושל קבלה שכבר הוגשה
- בידוד מלא בין משתמשים (נבדק גם בגישה ישירה לכתובות)
- שינוי אחרי אישור מבטל את האישור; לחיצה כפולה לא שולחת פעמיים
- עמוד ניהול: הזמנות, כתובת בדיקה/אמת, ספירת מצבים, בלי תוכן קבלות

עדיין לא קיים:
- **שליחה בפועל** (Gmail, שלב 4). בקשה מאושרת נשמרת במצב ״אושר — השליחה מושבתת״ ולא נשלח שום מייל.
- פענוח אוטומטי של סכום וסיווג; כרגע מזינים ידנית.
- זיהוי כפילות בין שני קבצים שונים של אותה קבלה (למשל צילום וגם PDF); דורש פענוח.
- ניסיון חוזר אוטומטי, מחיקה לפי מדיניות שמירה, אירוח.

## הפעלה מקומית (Windows)

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env          # ולערוך SECRET_KEY
.venv\Scripts\flask --app app create-admin your@email.com
.venv\Scripts\flask --app app run
```

פותחים `http://127.0.0.1:5000` ואחריו נתיב ההזמנה שהודפס (`/invite/...`) כדי להגדיר שם וסיסמה.

## בדיקות

```
.venv\Scripts\python -m pytest -q
```

הנתונים והקבצים נשמרים ב־`instance/` (מחוץ ל־Git).
